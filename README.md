# saeul-newsscrape

한국수력원자력·새울원자력본부·한수원·새울본부 키워드를 실행할 때마다 구글 뉴스 RSS로 실시간 검색해 보여주는 기사 스크랩 앱.

## 실행
```
python news_scrap.py
```
또는 `실행.bat` 더블클릭. 브라우저가 자동으로 열립니다 (http://127.0.0.1:8765/).

- Python 3 표준 라이브러리만 사용 (설치 불필요)
- 탭·키워드는 `newscore.py`의 `TABS_CFG`에서 수정

## v2.0 탭 구성
새울본부를 **메인 탭**(처음 열리는 탭)으로 하고, 탭마다 해시태그 키워드로 구글 뉴스를 수집합니다. 탭은 눌렀을 때 그 탭만 불러옵니다.

| 탭 | 키워드 |
|---|---|
| **새울본부 (메인)** | #새울원자력본부 #새울본부 (+ 울산 지역 신문 수집) |
| 한수원 | #한국수력원자력주식회사 #한국수력원자력 #한수원 #한수원(주) |
| 한울본부 / 고리본부 / 한빛본부 / 월성본부 | 각 #○○원자력본부 #○○본부 |
| 해외사업소 | #바라카건설소 #미주지사 #유럽지사 #엘바다건설소 #체르나보다TRF건설소 #체르나보다설비개선건설소 #두코바니건설소 |
| 양수건설 | #영동양수건설소 #홍천양수건설소 #포천양수건설소 |
| 수력양수 | #한강수력본부 #청평·삼랑진·무주·산청·양양·청송·예천양수발전소 #원자력수소융복합센터 |
| 연구보건 | #중앙연구원 #방사선보건원 |
| 기타 기관 | #인재개발원 #구매기술센터 #공간디자인센터 |

- 탭·키워드는 `newscore.py`의 `TABS_CFG`에서 관리합니다(서버와 화면이 `/api/tabs`로 같은 설정을 씁니다).
- 지명이 들어간 시설·기관명(양수건설·수력양수·연구보건·기타 기관 탭, #미주지사 #유럽지사)은 구글 뉴스가 느슨하게 검색해 관련 없는 글이 섞이므로 **'한수원/한국수력원자력'이 함께 나온 기사만** 가져옵니다.
- v1.0은 git 태그 `v1.0` 으로 보존되어 있습니다.

## 기능
- 출처: 구글 뉴스 RSS. 새울본부 탭은 울산 지역 신문 8곳(울산뉴스넷·울주신문·울산시민신문·울산신문·경상일보·울산제일일보·울산종합일보: 사이트 검색 결과 수집, 울산매일: 전체기사 RSS 최근 50건에서 키워드 필터)도 함께 수집
- 유사 기사 묶기: 제목 유사도로 같은 사안의 기사를 네모 상자로 묶어 표시
- 스팸·광고 숨김: 도박/게임 사이트 글 자동 표시 후 기본 숨김 (`newscore.py`의 `BLOCKED_SOURCES`, `SPAM_RE`)
- 기자 이름: 지역 신문은 목록·본문에서, 구글 뉴스 기사는 같은 신문사 기사를 빙에서 찾아 읽습니다. 못 얻으면 '기자 미확인'
- 스크랩: ☆ 클릭으로 저장(브라우저 저장), CSV 내보내기·목록 복사
- 주간 AI 요약: 탭마다 최근 7일 기사를 AI로 요약(1시간 공유). 메인 탭은 매주 처음 열 때 자동 생성
  - 환경변수 `GEMINI_API_KEY`(Google AI Studio 무료 키) 또는 `ANTHROPIC_API_KEY` 중 하나 필요. 둘 다 있으면 Gemini 우선
  - 로컬: `$env:GEMINI_API_KEY="..."` 후 실행 / Vercel: Project Settings -> Environment Variables 추가 후 Redeploy
  - 모델 변경: `GEMINI_MODEL`, `SUMMARY_MODEL`(Claude)
- 모바일 최적화·PWA(홈 화면 설치, 오프라인에서 마지막 목록)
